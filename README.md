# Music Genre Finder 🎵

A Chrome extension that detects songs from Spotify search results
and displays their musical genre.

## Tech Stack

- Chrome Extension - Manifest V3
- JavaScript
- Node.js
- Express.js
- Last.fm API

## Features

- Detects song and artist from Spotify
- Fetches genre using Last.fm
- Displays genre directly on Spotify
- Prevents duplicate API requests
